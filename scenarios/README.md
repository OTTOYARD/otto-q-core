# scenarios/ — the canonical failure-scenario library (C7.3)

Nine canonical failure scenarios (CLAUDE.md C7), each a committed data file.
`status` is honest: **executable** = a live twin injector exists today (named in
`mechanism`); **partial** = executable with a stated gap; **provisional** = the
injector arrives with named future work (pack data or C9). C8 runs every
executable scenario × every C5 policy on the benchmark depot via the existing
cert harness (`ottoq_cert_arm_start/step/finish`), all keyed by seed + run ID.
